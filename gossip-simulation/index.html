How It Works

1. Periodic Gossip: Every 3s, each active node picks a random peer

2. Exchange Tables: Nodes exchange routing tables (active & down nodes)

3. Version Comparison: Vector clocks determine which info is newer

4. Update & Sync: Nodes update their tables with fresher information

5. Failure Detection: Unreachable nodes are marked as down
